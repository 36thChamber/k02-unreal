# Unreal Martial Arts Game — Project Brief

Status: early concept and technology evaluation. This brief records the intended direction from design conversations; it is not evidence that any purchased package has been integrated or tested.

## Vision
Build a challenging third-person 3D martial-arts action game in Unreal Engine. Core inspiration: Sifu's responsive physical combat and crowd encounters, Sekiro's precise defense/posture pressure, and Souls-like difficult boss encounters. Focus first on a polished, single-player combat vertical slice; plan for two-player boss co-op later, and PvP only much later.

## Visual direction
**Anime-first, dark stylized 3D, not photorealism.** References: 1990s Akira, Ghost in the Shell (1995), Evangelion. Strong graphic silhouettes, distinctly anime facial proportions, deliberately simplified materials, high-contrast shadows, cinematic framing, industrial/urban decay, rain, concrete, neon, underground structures and psychological atmosphere. Modern fully 3D gameplay rendered with a cohesive anime-like aesthetic. Avoid drifting into realistic MetaHuman-looking skin/faces or generic fantasy photorealism. Cel shading is a candidate, not a fixed technical solution.

## Combat principles
- Fast, responsive controls; meaningful attack commitment and recovery.
- Punches, kicks, light/heavy strings, stances and directional defense (initially a small set of well-polished moves).
- Precise hit detection, reliable hit reactions, collision and damage.
- Blocking, perfect parries, dodges, counters; tune input buffering/cancel windows through playtesting.
- Health and posture/guard-break concept; stamina only if it improves pacing.
- Readable enemy telegraphs, boss attack patterns, punish windows, phase transitions.
- Skill-based difficulty, not simply inflated enemy HP.
- Later: multiplayer-safe combat authority/replication, co-op bosses, then PvP.
